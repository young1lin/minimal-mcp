# 项目介绍

这个项目主要是 MCP 教学使用，包含 Python 和 Java 以及 Go 的项目。

主要的代码实际上是有由 Claude Code 生成，抽象定义，DTO 定义是由我写大纲编写，只需要给官网的 JSON 就能生成对应的 DTO。
Java 的代码因为本地想只通过 Maven + Java 21 来实现，不想加其他的依赖，包括 Http 请求都是用 11 的 HttpClient 来实现。但是 Windows  上
有兼容问题，就算了。所以 Java 项目只是个简单的示例，并不能算是完整的 MCP 项目。

Python 代码，非常简单，尽可能简单描述，其中 _ 开头的表示内部私有方法和变量（编程常识），全部大写声明一次的变量是常量。


Go 项目 `claude-token-monitor` 主要是指向的另一个项目，没有一行代码是我写的，全靠 Claude Code Plan + GLM 4.7 + Sonnet 4.5 来生成，是交替使用的，大概用了两个亿的 Token。它实际上是和
`claude-code-hud` 做的是一样的事情，只不过它是用 npm，我用 Go 来写，用 npm 来进行分发包。目前 Token 的还没有统计。

# 测试

所有项目，都必须使用依赖注入，方便测试，并且测试代码要覆盖好边界，需要符合 AAA pattern 测试。

Mock、Spy、Stub、Fake、Dummy 等测试辅助工具，需要根据实际情况选择使用。

1. Java 就是用 JUnit5 + Mockito 来实现相关代码的测试，使用合适的 @MockBean 注解来注入 @Mock 下的对象，使用 @ExtendWith(MockitoExtension.class) 来扩展测试。使用 mvn test 来运行测试。
2. Python 就是用 pytest 来实现相关代码的测试，使用合适的 @mock.patch 来注入 @mock.Mock 下的对象，使用 @pytest.mark.parametrize 来参数化测试。使用 pytest 来运行测试。
3. Go 就是用 Go 自带的 testing + testify + gomock包来实现相关代码的测试。使用 go test 来运行测试。

# 代码格式化

所有项目，都必须使用代码格式化工具，并且格式化代码要符合规范，需要符合 Google Java Style、PEP 8、Go Format 等规范。

1. Java 就是用 Maven 的 spotless 插件来实现相关代码的格式化，使用 mvn spotless:apply 来格式化代码。强制格式化代码，如果没有格式化，则不能提交代码。
2. Python 就是用 black 来实现相关代码的格式化，使用 black --check . 来检查代码是否符合规范，使用 black . 来格式化代码。
3. Go 就是用 gofmt 来实现相关代码的格式化，使用 gofmt -w . 来格式化代码。
